ROMANTIC SURPRISE WEBSITE — QUICK SETUP

1. Unzip this folder.
2. Add your six pictures into assets/photos and name them exactly:
   photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg, photo5.jpg, photo6.jpg
   You can use .png too, but if so update the matching filenames in index.html.
3. Add your recorded voice message as:
   assets/audio/voice-note.mp3
4. Open index.html in a browser to test.
5. Personalize the letter in index.html. Search for "My favourite person".
6. To publish free with GitHub Pages:
   - Sign in to github.com and create a NEW repository.
   - Set it to Public and create the repository.
   - Upload all files INSIDE this folder (index.html, style.css, script.js, assets folder).
   - Open repository Settings → Pages.
   - Under Build and deployment, choose "Deploy from a branch".
   - Select branch "main" and folder "/ (root)", then Save.
   - Wait a minute or two; GitHub will show your live website URL in Settings → Pages.

IMPORTANT:
- Keep index.html at the repository root, not inside another nested folder.
- GitHub Pages is free for public repositories.
- Autoplay audio is usually blocked by browsers. This design uses a play control so the visitor can start your voice note.
- Replace all sample letter text with your own words.
